# 翻译规则（所有语言通用）

## 绝不翻译
- 代码块内**一切**（含注释、JSON 里的中文说明）
- 行内代码 `...`
- 命令、路径、URL、环境变量（`SNOWLUMA_*`）、JSON 字段名、文件名
- 程序返回的 message 值（如 `"配置保存成功，已热重载当前会话。"`）
- 要执行的命令字符串（如 `grep -E "远程桌面密码:"`）

## 必须保持
- 标题层级与数量（`#`/`##`/`###`）
- 代码围栏数量与语言标注
- 表格行数与分隔行
- 列表项数量
- 相对链接路径原样

## 上传方式
`ssh oracle 'cat > /目标路径' < 本地文件`
（tar 管道和大文件会超时断连）
传后 `md5sum` 双向核对。

# 伪中国语（zh-pseudo）的字形规则 ⚠️

**用日文汉字形体，不要用中文简体形体。**

不是疏漏 —— 伪中国语本质是「用汉字写日文语法」，字形取日文才自洽。
现有译文统一如此：対 86 / 実 174 / 応 67 / 様 15 / 図 / 発 / 経 / 単 …

| ✅ 用 | ❌ 不用 |
|---|---|
| 対 実 応 様 図 発 経 単 | 对 实 应 样 图 发 经 单 |
| 時 間 関 開 種 類 総 | 时 间 关 开 种 类 总 |
| 運 転 権 検 験 証 拠 録 | 运 转 权 检 验 证 据 录 |
| 説 読 変 換 選 択 連 続 | 说 读 变 换 选 择 连 续 |
| 優 級 別 構 造 設 置 値 | 优 级 别 构 造 设 置 值 |
| 態 錯 誤 異 常 測 試 | 态 错 误 异 常 测 试 |
| 庫 儲 削 除 編 輯 複 製 | 库 储 删 除 编 辑 复 制 |
| 帰 還 昇 降 版 認 鑰 帳 戸 | 归 还 升 降 版 认 钥 账 户 |

**硬指标：假名字符数必须为 0**（`\u3040-\u309f` `\u30a0-\u30ff` `\u31f0-\u31ff` `\uff66-\uff9f`）

有转换脚本：`STYLE/kanji-unify.js`（只改代码块外的正文，跳过围栏与行内代码）

# fence 内翻译规则（重要澄清）

原规则「fence 内一律不动」过于绝对。正确规则：

**要翻译**（同时满足）：
1. fence 无语言标记（``` 后不跟任何东西）
2. 内容是自然语言散文 / 列表 / 表格 / ASCII 示意图
3. 里面没有命令、路径、变量名、字段名（有的话只翻外围说明，符号保持）

例：
```
原因一：配置优先级
        运行时配置（onebot_<uin>.json）  >  代码默认值（DEFAULT_STATUS_COMMAND）
        → 改代码默认值对已有账号无效
```
这就是说明文字，该翻。

**不翻译**：任何带语言标记的 fence（```bash / ```json / ```ts / ```ini / ```jsonc …），**包括其中的注释**。
