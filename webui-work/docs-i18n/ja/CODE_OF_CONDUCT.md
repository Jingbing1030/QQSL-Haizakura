# コントリビューター行動規範 (Contributor Covenant Code of Conduct)


本文書は [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) を基に改変したものであり、Haizakura コミュニティがともに守る行動規範です。

## 私たちの誓約

コミュニティの一員、コントリビューター、メンテナーとして、私たちは次のことを誓います。Haizakura プロジェクトとコミュニティに参加するすべての人が、年齢、体型、可視・不可視の身体的差異、心身の障害、民族、性別的特徴、性自認と性表現、経験の程度、教育背景、社会経済的地位、国籍、外見、人種、宗教的信仰、または性的指向によって嫌がらせを受けることのないようにすること。

私たちは、開かれた、温かく、多様で、包摂的で、健全なコミュニティを築く方法で行動し、交流することを誓います。

## 私たちの基準

前向きなコミュニティ環境づくりに資する行動には、以下が含まれますが、これらに限りません：

- 他者に共感と善意を示す
- 異なる意見、見解、経験を尊重する
- 建設的なフィードバックを与え、かつ品位をもって受け入れる
- 責任を負い、私たちの誤りによって影響を受けた人に謝罪し、そこから学ぶ
- 個人だけでなく、コミュニティ全体の最善の利益に目を向ける

受け入れられない行動には、以下が含まれますが、これらに限りません：

- 性的な言葉や表現の使用、およびあらゆる形の性的注目や性的嫌がらせ
- 嘲弄、侮辱、中傷的なコメント、および人身攻撃や政治的攻撃
- 公的または私的な嫌がらせ
- 明示的な許可なく他者の私的情報（物理的住所やメールアドレスなど）を公開すること
- その他、専門的な場において合理的に不適切と判断され得る行為

## 適用範囲

本行動規範はすべてのコミュニティの場に適用され、個人が公の場でコミュニティを代表する場合の言動にも適用されます。本コミュニティを代表する状況には、以下が含まれますが、これらに限りません：プロジェクト公式のメールアドレスを使用すること、プロジェクト公式のソーシャルメディアアカウントを通じて投稿すること、指名された代表としてオンラインまたはオフラインのイベントに出席すること。

Haizakura に即して言えば、本規範は次に適用されます：

- 本リポジトリ（issue、PR、discussion、commit message、code review のコメントを含む）
- プロジェクト関連の QQ グループ、Telegram グループ、および将来追加され得る公式コミュニティ
- Haizakura の名義で対外的に開催されるあらゆる活動や交流

## 執行の責任

コミュニティのメンテナーは、私たちが受け入れ可能と判断する行動基準を解釈し執行する責任を負い、不適切、脅威的、攻撃的、または有害と判断した行為に対して適切かつ公正な是正措置を取ります。

コミュニティのメンテナーは、本行動規範に適合しないコメント、コミット、コード、wiki 編集、issue、その他の貢献を削除、編集、または拒否する権限と責任を有し、適切な機会に審査判断の理由を説明します。

## 報告方法

不適切な行為を目撃した、または自ら経験した場合は、以下のいずれかの窓口からメンテナーに**非公開で**連絡してください：

- QQ：[Haizakura-QQ](https://qm.qq.com/q/g3UMLpWALe)（管理者に個別チャットしてください。グループ内で公開しないでください）
- Telegram：[Haizakura-TG](https://t.me/napcatqq)（管理者に個別チャットしてください）

GitHub の issue や公開チャンネルに報告内容を直接投稿しないでください。関係者に二次的な被害を与える恐れがあります。

すべての苦情は速やかかつ公平に審査・調査されます。すべてのコミュニティメンテナーは、報告者のプライバシーと身体の安全を尊重する義務を負います。

## 執行ガイドライン

コミュニティのメンテナーは、以下の「コミュニティ影響ガイドライン」に基づいて、本行動規範に違反する行為の処置方法を判定します：

### 1. 是正 (Correction)

**コミュニティへの影響**：不適切な言葉遣い、またはコミュニティにおいて専門的でない、もしくは好ましくないと見なされるその他の行為。

**結果**：コミュニティのメンテナーによる非公開の書面警告。当該行為が規則に反する点を明確に示し、なぜ不適切であるかを説明します。公開での謝罪を求める場合があります。

### 2. 警告 (Warning)

**コミュニティへの影響**：単一の出来事または一連の行為による違反。

**結果**：警告および継続した場合の結果の説明。指定期間内、関係者との交流を禁止します。これには本行動規範の執行者への自発的な連絡も含みます。また、コミュニティの場および外部チャンネル（ソーシャルメディアなど）での交流を避けることも含みます。これらの条項に違反した場合、一時的または恒久的な追放につながることがあります。

### 3. 一時的追放 (Temporary Ban)

**コミュニティへの影響**：継続的な不適切行為を含む、コミュニティ基準への重大な違反。

**結果**：指定期間内、コミュニティとのあらゆる形の交流または公開での意思疎通を禁止します。この期間中、関係者との公的・私的な交流は一切できません。これには本行動規範の執行者への自発的な連絡も含みます。これらの条項に違反した場合、恒久的な追放につながることがあります。

### 4. 恒久的追放 (Permanent Ban)

**コミュニティへの影響**：継続的な不適切行為、個人への嫌がらせ、または特定の集団への攻撃や貶下を含む、コミュニティ基準への違反のパターンを示すこと。

**結果**：コミュニティ内でのあらゆる形の公開交流を恒久的に禁止します。
