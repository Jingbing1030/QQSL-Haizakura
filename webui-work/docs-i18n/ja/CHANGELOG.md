# 更新履歴


## 2.0.0

### アップグレード

- 最低実行環境を Node.js 24 に引き上げました。フル版は Node.js を同梱しています。Lite、SDK、MCP の利用者は先に実行環境を更新してください。
- ネイティブインターフェースを全面的に非同期化しました。アプリケーションとネイティブ成果物はセットで更新する必要があります。対応プラットフォームの完全版配布パッケージを使用してください。

### 更新

- ローカル QQ アカウントの識別、プロセス状態の診断、順序付きのアカウント通知を追加しました。
- WebUI が更新の一時保存と再起動時のインストールに対応し、設定・ログ・メッセージデータを保持するようになりました。
- グループ共有リンク、Qzone 投稿の詳細とコメントのページングインターフェースを追加し、SDK の型と MCP のアクションカタログを同期しました。
- 結合転送の引用プレビュー、グループアルバムのコメント、SILK の長さ、Highway のノード切り替えを改善しました。
- ネイティブ呼び出し、SQLite、アカウント終了、再接続の順序を整理し、リクエストのキャンセル、購読、タイマーの解放を修正しました。
- WebUI のアイドルポーリングを削減し、リバースプロキシの認証とバージョン比較を修正しました。
