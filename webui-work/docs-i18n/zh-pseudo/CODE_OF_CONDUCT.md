# 貢献者公約 (Contributor Covenant Code of Conduct)


本文档改編自 [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)、Haizakura 社群共同遵守之行為準則也。

## 我等之誓約

身為社群成員、貢献者、維護者、我等誓約：凡参加 Haizakura 工程与社群之人、不因年齢、体型、可見或不可見之身体差異、心身障害、族裔、性別特徴、性別認同与表現、経験程度、教育背景、社会経済地位、国籍、外貌、種族、宗教信仰、或性取向、而遭嫌擾也。

我等誓約、以営造開放、熱情、多元、包容、健全社群之方式行動且交流也。

## 我等之準則

有助於建立正向社群環境之行為、含以下而不限於此：

- 対他人展現共感与善意
- 尊重相異之意見、観点与経験
- 給予且優雅接受建設性反饋
- 承担責任且向受我等錯誤影響之人致歉、並自其中吸取教訓
- 關注者非僅個人、実為整个社群之最大利益也

不可接受之行為、含以下而不限於此：

- 使用情色化之言語或意象、及任何形式之性關注或性嫌擾
- 嘲諷、侮辱或貶損之評論、以及人身或政治攻撃
- 公開或私下之嫌擾
- 未經明確許可、公布他人之私密資料、例如物理或電子郵件地址
- 其他於専門場合可被合理認定為不当之行為

## 適用範囲

本行為準則適用於一切社群場所、亦適用於個人於公開場合代表社群之時之言行也。代表本社群之情形、含以下而不限於此：使用工程官方電子郵件地址、経工程官方社交媒体帳号発文、以指定代表身分出席線上或線下活動也。

具体至 Haizakura、本準則適用於：

- 本倉庫（含 issue、PR、discussion、commit message、code review 評論）
- 工程関連之 QQ 群、Telegram 群以及未来可能追加之官方社群
- 任何以 Haizakura 之名義対外発起之活動或交流

## 執行責任

社群維護者負責詮釈且執行我等所認定之可接受行為標準、且対任何其認為不当、具脅威性、冒犯性或有害之行為、採取適切且公正之糾正措置也。

社群維護者有権且有責削除、編輯或拒絶任何不符本行為準則之評論、提交、程式碼、wiki 編輯、issue 及其他貢獻、且於適切時機説明作出審核決策之理由也。

- QQ：[Haizakura-QQ](https://qm.qq.com/q/g3UMLpWALe)（私聊管理者、請勿於群内公開）

一切投訴皆会被及時且公平審査与調査也。一切社群維護者皆有義務尊重挙報者之隱私与人身安全也。

## 執行準則

社群維護者将依以下「社群影響指引」判定違反本行為準則行為之処置方式：

### 1. 更正 (Correction)

**社群影響**：使用不適切之言語、或其他於社群中被視為非専門或不受歓迎之行為也。

**後果**：由社群維護者私下提出書面警告、明確指出該行為違反規則之処並解釈其為何不妥也。可能要求公開致歉。

### 2. 警告 (Warning)

**社群影響**：経単一事件或一系列行為造成違規也。

**後果**：警告且説明持續行為之後果。於指定時間内禁止与関連人員互動、含主動連絡本行為準則執行者也。此含避免於社群場所及外部渠道（如社交媒体）之互動。違反此等条款可能導致臨時或永久封禁也。

### 3. 臨時封禁 (Temporary Ban)

**社群影響**：重大違反社群準則、含持續之不当行為也。

**後果**：於指定時間内禁止与社群為任何形式之互動或公開交流。此期間内不得与関連人員有任何公開或私下之互動、含主動連絡本行為準則執行者也。違反此等条款可能導致永久封禁也。

### 4. 永久封禁 (Permanent Ban)

**社群影響**：展現違反社群準則之模式、含持續之不当行為、嫌擾個人、或対某類群体為攻撃或貶低也。

**後果**：永久禁止於社群内為任何形式之公開互動也。
