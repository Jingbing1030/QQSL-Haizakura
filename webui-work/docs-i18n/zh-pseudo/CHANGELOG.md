# 更新記録


## 2.0.0

### 昇級

- 最低運行環境昇至 Node.js 24 也。完全版内蔵 Node.js；Lite、SDK 与 MCP 之利用者者先運行環境昇級必要也。
- 原生接口全面非同期化、応用与原生産物者成套更新必要也；該当平台之完全発行包使用請也。

### 更新

- 本地 QQ 帳号識別、工程状態診断与有序帳号通知追加也。
- WebUI 者暫存更新、再起動安裝対応、且設定、記録与消息資料保持也。
- 群分享連結、空間説説詳細与評論分頁接口追加、SDK 型与 MCP 動作目録同期也。
- 合併転送引用預覧、群相冊評論、SILK 時長与 Highway 節点切替改善也。
- 原生呼出、SQLite、帳号閉鎖与再接続順序整理、請求取消、購読与計時器解放修復也。
- WebUI 空閑輪詢削減、反向代理認証与版本比較修復也。
