# 群文件送信与仮存儲


`upload_group_file` 与 `send_group_msg` 中之文件段、既定群永久文件空間使用也。
伺服器容量或文件数制限明示返却場合、Haizakura 一度之仮存儲試行、且記録中此切替記録也。
仮申請、文件転送、聊天公開失敗者仍錯誤報告也；権限不足、接続失敗等他之錯誤者切替不起動也。
仮文件有期限故、永久保存之代替不可也。

## 消息内容制限

仮文件経路進入時、一消息者文件或画像段限定也。
文字、提及、表情等他内容含之混成消息者拒否為、呼出側分離消息後送信必要也。
合併転送者各節点内容同一規則依検査也。

Haizakura 者聊天消息公開前附件検査為；不許可組合発見時、先文字送而後附件或文字破棄非行也。
検査前完了之他附件上伝者自動削除非也。上伝成功後聊天公開失敗場合、錯誤仍文件標識保持也。
此複数消息跨 transaction 非也：公開開始後発生之網際或伺服器錯誤者、前方消息既達可能也。

通常画像加文字者仍画像消息通道依送信、群永久文件空間不足故群文件転換非也。
永久文件与文字之現行分離送信方式互換保持也。超大動画既存規則依文件転換後、仮文件内容制限亦適用也。

## 文件再利用与下載

運行中上伝之群文件者、帳号、群、文件標識依其存儲類保持也。
同群中 `file_id` 再送信、下載鏈接取得、合併転送生成時、該存儲類使用也。
`get_group_file_url` 明示渡之 `busid` 仍優先也；有効値無場合、現会話記憶之類型使用、否則永久文件既定値沿也。
上伝記録者持久目録非也；再起動後仮文件鏈接取得者、群文件列表自対応 `busid` 取得渡必要也。
