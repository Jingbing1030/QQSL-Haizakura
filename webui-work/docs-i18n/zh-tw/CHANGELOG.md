# 更新記錄


## 2.0.0

### 升級

- 最低執行環境提升至 Node.js 24。完整版內建 Node.js；Lite、SDK 與 MCP 使用者需先升級執行環境。
- 原生介面全面非同步化，應用程式與原生產物需成套更新；請使用對應平台的完整發行包。

### 更新

- 新增本機 QQ 帳號辨識、行程狀態診斷與有序帳號通知。
- WebUI 支援暫存更新、重新啟動安裝，並保留設定、日誌與訊息資料。
- 新增群分享連結、空間說說詳情與留言分頁介面，同步 SDK 型別與 MCP 動作目錄。
- 改進合併轉發引用預覽、群相簿留言、SILK 時長與 Highway 節點切換。
- 整理原生呼叫、SQLite、帳號關閉與重新連線順序，修正請求取消、訂閱與計時器釋放。
- 減少 WebUI 閒置輪詢，修正反向代理驗證與版本比較。
