# 貢獻者公約（Contributor Covenant Code of Conduct）


本文件改編自 [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)，是 Haizakura 社群共同遵守的行為準則。

## 我們的承諾

身為社群成員、貢獻者、維護者，我們承諾：讓每一個參與 Haizakura 專案和社群的人，不因年齡、體型、可見或不可見的身體差異、身心障礙、族裔、性別特徵、性別認同與表達、經驗水準、教育背景、社會經濟地位、國籍、外貌、種族、宗教信仰、或性傾向，而遭受騷擾。

我們承諾以營造開放、熱情、多元、包容、健康社群的方式行事和互動。

## 我們的準則

有助於建立正向社群環境的行為包括但不限於：

- 對他人展現同理心與善意
- 尊重不同的意見、觀點與經驗
- 給予並優雅地接受建設性回饋
- 承擔責任並向受我們錯誤影響的人致歉，並從中學習
- 關注的不僅是個人，更是整個社群的最大利益

不可接受的行為包括但不限於：

- 使用情色化的語言或意象，及任何形式的性關注或性騷擾
- 嘲諷、侮辱或貶損性的評論，以及人身或政治攻擊
- 公開或私下的騷擾
- 未經明確許可，公布他人的私人資訊，例如實體或電子郵件地址
- 其他在專業場合中可被合理認定為不當的行為

## 適用範圍

本行為準則適用於所有社群場所，也適用於個人在公開場合代表社群時的言行。代表本社群的情形包括但不限於：使用專案官方電子郵件地址、透過專案官方社群媒體帳號發文、以指定代表身分出席線上或線下活動。

具體到 Haizakura，本準則適用於：

- 本儲存庫（含 issue、PR、discussion、commit message、code review 評論）
- 專案相關的 QQ 群、Telegram 群以及未來可能新增的官方社群
- 任何以 Haizakura 名義對外發起的活動或交流

## 執行責任

社群維護者負責詮釋並執行我們所認定的可接受行為標準，並將對任何他們認為不當、具威脅性、冒犯性或有害的行為採取適當且公正的糾正措施。

社群維護者有權且有責任刪除、編輯或拒絕任何不符合本行為準則的評論、提交、程式碼、wiki 編輯、issue 及其他貢獻，並將在適當時機說明做出審核決策的理由。

## 舉報方式

如果你目擊或親身經歷了不當行為，請透過以下任一管道**私下**聯絡維護者：

- QQ：[Haizakura-QQ](https://qm.qq.com/q/g3UMLpWALe)（私訊管理員，請勿在群組內公開）
- Telegram：[Haizakura-TG](https://t.me/napcatqq)（私訊管理員）

請勿在 GitHub issue 或公開頻道直接發布舉報內容，以免對相關方造成二次傷害。

所有投訴都會被及時和公平地審查與調查。所有社群維護者都有義務尊重舉報者的隱私與人身安全。

## 執行準則

社群維護者將依據以下「社群影響指引」來判定違反本行為準則之行為的處置方式：

### 1. 更正（Correction）

**社群影響**：使用了不恰當的言語，或其他在社群中被視為不專業或不受歡迎的行為。

**後果**：由社群維護者私下提出書面警告，明確指出該行為違反規則之處並解釋為何不妥。可能要求公開致歉。

### 2. 警告（Warning）

**社群影響**：透過單一事件或一系列行為造成違規。

**後果**：警告並說明持續行為的後果。在指定時間內禁止與相關人員互動，包括主動聯絡本行為準則執行者。這包括避免在社群場所及外部管道（如社群媒體）的互動。違反這些條款可能導致暫時或永久封鎖。

### 3. 暫時封鎖（Temporary Ban）

**社群影響**：嚴重違反社群準則，包括持續的不當行為。

**後果**：在指定時間內禁止與社群進行任何形式的互動或公開交流。在此期間不得與相關人員有任何公開或私下的互動，包括主動聯絡本行為準則執行者。違反這些條款可能導致永久封鎖。

### 4. 永久封鎖（Permanent Ban）

**社群影響**：表現出違反社群準則的模式，包括持續的不當行為、騷擾個人、或對某類群體進行攻擊或貶低。

**後果**：永久禁止在社群內進行任何形式的公開互動。
